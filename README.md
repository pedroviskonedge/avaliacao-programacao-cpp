# Avaliação de programação em C++

Atividade acadêmica de Pedro Roberto com exercícios de entrada e saída, cálculos e estruturas condicionais.

## Conteúdo

- Comparação de números e verificação de idade.
- Cálculo de média e classificação de resultados.
- Identificação de números positivos, negativos, pares e ímpares.
- Calculadora com `switch`.
- Cálculos de valores e formas de pagamento.
- Relatórios de dados no terminal.
